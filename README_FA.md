# پول‌یار — اپلیکیشن آفلاین مدیریت هزینه شخصی

## امکانات
- رابط فارسی، راست‌چین و مناسب موبایل
- واحد پول افغانی (؋)
- ثبت درآمد و مصرف با تاریخ و دسته‌بندی
- محاسبه خودکار موجودی و گزارش ماهانه
- بودجه‌بندی دسته‌ای و نمایش عبور از سقف بودجه
- ذخیره‌سازی محلی و عملکرد بدون اینترنت
- تهیه و بازیابی نسخه پشتیبان JSON
- حذف تراکنش‌ها و بودجه‌ها

## ساخت فایل APK
1. Android Studio جدید را نصب کن.
2. این پوشه را در Android Studio با گزینه **Open** باز کن.
3. اجازه بده Gradle Sync کامل شود. در اولین ساخت ممکن است برای دریافت Android Gradle Plugin و Android SDK به اینترنت نیاز باشد.
4. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کن.
5. خروجی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## مهم
این بسته پروژهٔ کامل قابل‌ساخت در Android Studio است؛ فایل APK از پیش کامپایل‌شده نیست، چون محیط ساخت اندروید در این جلسه نصب نیست. اطلاعات روی همان دستگاه نگهداری می‌شود. پاک‌کردن داده‌های برنامه می‌تواند آن‌ها را حذف کند؛ نسخه پشتیبان بگیر.
